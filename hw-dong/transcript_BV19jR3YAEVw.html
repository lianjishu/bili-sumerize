01

满屏的「烂书之王」，和没人追问的问题

00:00 ↗

00:00昨天我在 B 站刷到一个视频，讲的是谭浩强的《C程序设计》——说这本书误人子弟，作者是烂书之王，「毒害了中国大学生的罪魁祸首」。今天我再搜了一下「烂书之王」：B 站上整个都是这类视频，头像清一色用的都是谭浩强。看来「这本书很烂」，已经成了共识。

00:45但有一个问题值得琢磨：这本书既然这么烂，为什么直到今天，高校里还在普遍采用它？连计算机等级考试，考的也是他这本 C 语言。

02

更少人知道的头衔：抄袭大王

01:00 ↗

01:00很多人只知道谭浩强是「烂书之王」，不知道他实际上还是「抄袭大王」。他这本书的内容，可以说几乎全部抄袭自 C 语言发明者写的那本书——就是后来被翻译成中文的那本（K&R 的《The C Programming Language》）。按他的判断：谭浩强的书，90% 是抄的。

01:53多少年来，中国大学把这本书奉为经典：C 语言课用它，其他专业开 C 语言也用它。而在中国这种不重视知识产权的环境下——说到这里他还自嘲了一句「这样一说，会不会把我的视频给封了」——抄袭的教材、抄袭论文的人，照样混得风生水起。这不是某一个人的问题，而是一种普遍现象。这本书还畅销得不得了，据说卖了几千万册，在中国 C 语言教学界统治了很多年。

02:40他推测抄袭的经过：原著是 1978 年出的，那时候还没有中文译本，所以谭浩强抄的只能是英文版——翻译过来据为己有，然后打一个中英文的信息差：中文读者没人看过英文原著，自然无从追究。其实只要有人读过 C 语言发明者写的那本书，一对比就知道全是抄的。可就是没有人去计较、去深究。连计算机等级考试，都在考他这本书的内容。

03

「怪他没跟进 C99 标准」是怪错了人吗

03:31 ↗

03:31接下来他放出另一家视频的文案：

「好多人说谭老的 C 语言教材很烂，那么他的书为什么那么烂？这一点很多人都没思考过，网上的评论都不在一个焦点上。把罪责归于谭老写的《C程序设计》，实在是很滑稽。许多人批评的重要理由是『不符合 C99 标准』——从这个方向怪谭老、讽刺谭老，其实真的怪错了人。虽然我不太建议初学者用红皮书学这门语言，但书的作者谭老是一个值得尊敬的人：1972 年 C 语言才推出第一个版本，当时谭老 38 岁；1989 年才完成第一次标准化，俗称 C89，当时谭浩强 55 岁；1991 年，谭老 57 岁的时候《C程序设计》出版；1999 年 C99 标准问世时，他已经 65 岁。计算机行业发展迅猛、新旧更替……」 —— 其他 UP 主视频文案（由本视频播放，大意）

04:30对此他的态度是：这段文案的作者其实什么也没搞清楚——嘴上说「怪错了人」，自己连谭浩强的书和 C 语言标准的先后关系都没弄明白，属于瞎说。这本书烂，和符不符合 C 语言标准根本没有关系：标准还没出来的年代，谁也不可能「完全照着标准写」；拿「书比 1989 年的标准还早」说事，是连 C 语言发明者 1978 年就出了书都不知道。

05:02书烂的真正原因就两条：一是内容是抄的，例子什么都是用人家的；二是抄还抄不好。他不可能老老实实全盘翻译——那样一眼就会被看出来。所以他抄一部分、自己「发挥」一部分，把人家原本讲得清楚的东西越讲越死、越讲越晦涩，还显得自己钻研得很深、很有料。实际上这是一个根本不懂教育、不懂教学的人，说他写的书误导中国学生，一点都不为过。

04

真正「毒害」大学生的是大学和老师

07:00 ↗

07:02他认为那段文案里有句话说得不错：谭浩强这本书虽然占据着权威地位，但用不用，最终还是取决于大学。所以真正坑害中国大学生的，其实不是谭浩强——他当年把书写成那样，可当年选教材的空间就那么大，不用他的用谁的？关键在高校：大学为什么要用它？

07:40大学老师选教材是完全有自主权的。稍微像样一点的大学，不会强迫老师必须用某本教材，老师理应挑选自己认为好的书。可是中国这么多大学、这么多计算机专业的老师，为什么就没有一个不用这本书？全都在用。学校规定要用，老师自己也说要用，大家都用，于是接着用。从这一点就能看出来：中国的大学就是拿着这种很老套、很烂的教材在教大学生。

08:33由此延伸，之前视频里讲过的软件工程也一样：中国大学里教软件工程的老师，绝大部分根本不懂软件工程，也没在企业干过，只能瞎讲；用的教材还是多少年前那些根本没用的旧书。中国的很多教材都很烂、都很老，却总是占据统治地位，多少年也不允许更换，宁可一直用传统的。中国的大学太僵化了。说到底，就是根本对大学生不负责：老师的心思全在科研、发论文、评职称、申课题上，没有心思真正从事教学；课件做得一塌糊涂，连本科生都不如；上课拿着破书随便照本宣科、糊弄一下就完事。

10:08顺带自荐：像他讲的《算法设计与分析》这门课，自认为讲得很清楚，大家可以了解一下。并点名很多大学在用的王晓东《计算机算法设计与分析》——在他嘴里，是「和谭浩强的书一样烂」的教材。

「入门 C 语言有很多种书籍，偏偏选择的是一本过时的、应付考试的书籍；在一个快速发展的时代，也不修改，继续用这些过时的书籍。」 —— 视频中引用的评论（大意）

11:11念完评论他又吐了个槽：视频下面还有人推荐《C Primer Plus》《C++ Primer》之类的书；网上也一大堆人吹捧《C Primer》、什么《算法导论》。他直言这些书「也很一般、不怎么样」，自己学编程语言不会看那些书，也劝人别看——与其看这些书，不如在网上看看文章。越是烂的书反而越吃香，因为它有名了。（此为 UP 主个人观点，原话如此。）

05

题外话：我的书为什么没人用

11:56 ↗

11:56说到「烂书反而吃香」，他忍不住自嘲：像我写的这种「特别好的书」，就没人用。他之前写的《C++17从入门到精通》（清华大学出版社），自认为语法部分讲得很好，实战项目也非常多，却没有一个大学采用——因为那些老师根本不知道你的书，也不会去看你是什么人。

12:31纸质书出版走不通，他就把内容做成电子版放在网上卖，买的人寥寥无几，所以暂时也没什么积极性把连载项目补完；但他表示会持续更新这本书，读者有反馈就会修改。新电子书是在《C++17从入门到精通》基础上修订的，主要是更新到 C++23 标准，所以不再叫《C++17》，而叫《现代C++编程实战》。

13:25说到 C++，他又绕回老生常谈：现在大学里教的还普遍是「传统 C++」，多少年不变，根本不想用新的 C++ 教学生——和谭浩强的 C 语言一模一样，也是在误人子弟。

06

同样的文案：六千播放 vs 二十五万播放

13:53 ↗

13:53他说自己就是昨天刷到那个视频才想做这一期的，顺手对比了播放量：讲同样文案的男 UP 主只有六千多播放，而一位女 UP 主的同类视频已经有 21.4 万，后来涨到 25 万。他的感叹是：自媒体还是女生做占优势——不管讲什么内容，只要年轻女生出镜，播放量就在那儿；就算内容和谭浩强的书一样「烂」，照样很多人看。

15:20他点开那位女 UP 主的视频，承认两边文案几乎一样，也不知道是不是互相抄的，但人家的播放量就是 24 万+：

「不符合 C99 标准。1934 年谭浩强老先生出生，到今天已经 88 岁高龄。网上有很多段子这样评论，比如把 C 语言之父说成谭浩强……很多人开始怪谭老，这个方向就不对了，甚至各种讽刺谭老，其实这真的是怪错了人。但书的作者谭老，是一个值得尊敬的人。」 —— 其他 UP 主视频片段（由本视频播放，大意）

15:51他的评价：这些文案的意思大同小异，套路都是同一个——「谭浩强的书很烂，但谭老人是好人，最后把锅甩给中国大学」。

07

借题发挥：抄袭的越火，干货越无人问津

16:22 ↗

16:25他从这件事延伸开去：这些互相抄袭的视频，和谭浩强那些书一个样——越是抄袭的越火，越是有真干货的，越是无人问津。所谓「乌合之众」，大多数人都人云亦云，崇拜权威，其实没有自己的独立思考。

16:55他又讲了一段自己的观察：很多人自以为在思考——理论、说法一套一套的，口才好得不得了，你根本讲不过他；但他讲的东西，其实都是常识，是长期被同质化信息喂养出来的结果。人的思想，本质上就是所接收信息训练出来的结果。

08

「抄了就要超越」

17:26 ↗

17:26被引用的视频里还有一段：「2000 年之后，经典的新语言书籍层出不穷，甚至可以用百花齐放、百家争鸣来形容了，谭老的书已经毫无竞争力了。」——紧接着那位 UP 主开始推荐自己的 C++ 学习资料和教程。他对此的吐槽是：你看，这个和谭浩强的书一样烂，给人家塞这么多东西，人家看得过来吗？越是烂的，越是吃香。

17:55他又刷了一圈同类视频：又一个 24.9 万播放的、一个 9.3 万的，还有一个 179 万的——那个 179 万的和谭浩强关系不大。随后翻到一篇类似「那些年我们读过的烂书」的讨论，说其中清华大学出版社的书占了不少；并判断这文章本身也不是原创，同样是抄来的，而且抄得比原作还糟。

18:45他的观点：抄袭不可怕——模仿本来就是造一座桥，抄了之后你要超越原作才行；抄了人家的书，不但没超越反而变得更烂，那这个抄袭就没意思了。他还引了马云那句「现在假货比真货好」：仿品有的质量确实不差，或者价格低、性价比比真货高得多；对比之下，抄袭书抄完反而更烂，高下立判。

09

收尾：锅最终回到大学

19:30 ↗

19:30最后总结全片：计算机专业很多教材都是烂教材，多少年不更换。除了原著和书本身的问题，更主要的原因，还是开头第一个视频讲到的那件事——在中国的大学，和中国的大学老师：整天想着科研、不认真教书的大学老师，连课件都做不好，连一本好书都不会选，拿一本破烂书随便捣鼓，或者把别的老师的课件拿过来照搬了事。

20:09照例是广告收尾：「感兴趣的可以买我的书，《现代C++编程实战》——买完你们就可以自己评价，它到底是不是烂书、是不是烂书之王。谢谢大家。」
