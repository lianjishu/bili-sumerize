笔记是怎么做出来的

  • yt-dlp 抓最佳音轨（format 30280）+ 官方章节元数据
  • ffmpeg 转 192kbps mp3，与元数据时长双向校验（偏差 ≤0.0001%）
  • faster-whisper large-v3-turbo + CUDA fp16 中文转写，覆盖率校验 ≥99.9%
  • 按官方章节拆章，逐段精读提炼为结构化小节
  • 动态生成 SVG 图解（时间线 / 流水线 / 概念图 / 对比图）
  • 拼装为内联 CSS + 内联 SVG + base64 封面的单文件 HTML
  • DOM 级体检 + 分段拼接整页截图 + 切片视觉抽查
