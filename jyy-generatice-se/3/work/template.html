ASR 明显误识别修正表

  • 「get init / get add / get commit / get status / get blame / get bisect」→ git init / add / commit / status / blame / bisect（语音同音误写）
  • 「get rebase 是零 off 十」→ git rebase 是 reflog 之外（讲师口语：rebase 比 reflog 更少见）
  • 「Bitkeeper」→ BitKeeper（Linux 内核曾用的商业版本控制工具）
  • 「Linux 的作者 Linux」→ Linux 的作者 Linus（Linus Torvalds）
  • 「I did some cool steps / cool stuff」→ 讲师刻意演示的反面示范 commit message，保留原样
  • 「DS store / 点 ds-store」→ .DS_Store（macOS Finder 生成的隐藏索引文件）
  • 「agency.md / agent 的 MD」→ AGENTS.md（agent 协作规则文件）
  • 「Avisa type」→ a verb / a type（Conventional Commits 规范原句）
  • 「考案神」→ 盘古之白（中英文之间加空格的排版惯例，讲师口语）
  • 「incoming change」→ accept incoming change（IDE 冲突解决按钮）
  • 「fixed 警三」→ fixed #3（GitHub issue 自动关闭语法）
  • 「learn git branching.js.org」→ learngitbranching.js.org（Git 交互教学网站）
  • 「code.cs61a.au」→ code.cs61a.org（UC Berkeley CS61A 在线 IDE）
  • 「Deep Seek Flash Division 的版本」→ DeepSeek 的 Flash 档模型（讲师原话，指便宜档位）
