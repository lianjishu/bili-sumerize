开场 & 版本管理

00:00 开始播放

本章看似是闲聊，其实全部在讲同一件事：在 AI 什么都能做的时代，人还剩下什么是值得学的。答案不在「知识点」里，而在注意力和对世界的感知上。

1.1开头：一次 GPT-6 的现场演示

00:00

开场直接放了一段 GPT-6 的现场演示作为这学期的起点。上半年还在讨论 GPT-5.6s，几个月之后版本的迭代已经要重新理解一次。老师用这类演示来说明一件事：技术演进的速度已经超出了「按学期更新教学内容」的节奏。

为什么用演示开场
  • 先让同学对「能力上限」有一个体感，再谈课程安排才有效
  • 这些能力不是未来的可能性，而是当下就可以用到的东西
  • 课程的立场：不追着讲工具，而是讲判断力——什么时候该用、用到什么程度

1.2代码正在变得不需要人读

02:00

老师提到一个正在发生的转折：过去写代码是为了让人读懂，现在越来越多的代码是写给机器执行的——人不再需要逐行阅读它。这直接冲击了几十年来的工程惯例（命名、注释、可读性）。

1.3AI 时代还要不要学数据库和操作系统

04:40

这是全章最实在的一段。老师先复述了同学最常问的问题：既然 agent 都会写，为什么还要学数据库、操作系统、编译原理这些「底层」？他没有直接给答案，而是打了一个类比。

1900 年代的司机必须懂机械——会修化油器、会换轮胎、听得出发动机异响。今天的自动驾驶不需要你懂这些。但这不意味着机械知识没用了，而是它的用途变了：不再是开车的前提，而是理解限制、做出判断的背景。

——讲师用汽车与驾驶的类比说明「底层知识」地位的迁移
问题的表层
「学了这个还有用吗」——按「会不会被 AI 替代」来判断知识价值
问题的深层
「我能不能判断 AI 做得对不对」——这才是底层知识真正的作用
结论
底层知识从「操作技能」变成了「审查能力」，它不再帮你做事，而是帮你判断
具体到本课
不懂 Git 的对象模型，就没法判断 agent 那套「重写历史」的操作是否安全
值得记下的判断

老师在这一段的立场很明确：不是「要不要学」，而是「为什么学」发生了改变。为了动手而学、与为了判断而学，是两种完全不同的学习方式。

1.4惊人的注意力

07:40

老师反复提到的一个习惯，越到后面越重要，可以说贯穿了整门课：看到别人给你的答案之前，先自己想一想你会怎么做。

惊人的注意力 · 具体做法
  • 看到一个结论，先问「如果是我，我会怎么做」，再看别人怎么做的
  • 看到一次报错、一次冲突、一次失败，停下来一秒，看清楚它长什么样
  • 学生时代的时间成本极低——一秒钟的观察，换来的是一辈子的印象
  • 关键不是「多花时间」，而是把注意力放在别人会跳过的地方

1.5第一个博士生的 U 盘事故

10:20

老师讲了一个自己带过的故事：第一个博士生把研究数据放在 U 盘里，U 盘坏了，数据没了。这件事后来成了他坚持用版本控制的原因，也成了这一讲的叙事起点。

他借此说明：版本管理最初的动机不是「多人协作」，也不是「工程规范」，而是一个非常朴素的需求——我想回到上一个版本，看看那时候我写的是什么。

这一段的落点

所有版本控制系统的第一性原理，都可以从一个学生「怕文件丢、怕改错」的处境里推出来。先有需求，后有工具——这是老师反复示范的思考方式。

1.6我要的是对世界的感知能力

12:40

接着上面的话题，老师澄清了一件事：学习的产出不是一个知识点清单，而是对世界的感知能力——能不能判断一件事会发生什么、后果有多严重、哪个方向是对的。

为什么「感知」比「知识」更重要
  • 知识可以随时问 AI 得到，但「该问什么」问不出来
  • 感知能力决定了你能不能在信息不足时做判断
  • 它只能通过一次次真实的观察、失败、复盘积累

1.7香港与南京的地铁标识

15:00

这一讲里最精彩的类比之一。老师比较了香港地铁与南京地铁的站内标识设计：香港的出口指示牌在地上、在天花板上、在每一个转角处都有；南京的则往往集中在某个位置。

他由此引出一条通用原则：当一个人处于「需要做决定的那一刻」，应该把这个决定所需的所有信息，放在他所在的那个位置。信息要放在发生的地方，而不是放在「你应该去看」的地方。

1.8在脑中先实现一遍

19:40

章末给了一个具体的学习方法，后面第 3 章讲 Git 底层时会再次用到：在做之前，先在脑子里实现一遍。

virtually implement：四步
  1. 明确需求——「我想回到上一个版本」
  2. 自己设计一个最小方案——「那就每次复制一份目录，再加个命令列出所有版本」
  3. 发现这个方案的缺陷——「目录会爆炸、无法比较、无法多人协作」
  4. 对照真实实现——「原来 Git 是这么解决这些缺陷的」
本章小结

第 1 章没有讲任何 Git 命令，但它是第 2、3 章的前提：先把「学什么」想清楚，再去看「怎么用」。注意力的价值在于，它让你在第 2 章看到冲突现场时，不只是「修好了」，而是「看懂了」。
