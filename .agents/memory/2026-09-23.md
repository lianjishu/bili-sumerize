### 本机环境踩坑（重要，下次直接用）

1. **curl 不可用**：静默失败或极慢。一律 `python -c` + `urllib` 下载。
2. **`rm` 被沙箱接管**：失败会让 `&&` 链中断。要重下就换文件名，别先删。
3. **Chrome cookies 取不到**（App-Bound Encryption，DPAPI 解密失败）→ 改用 **Firefox**
   提取并导出 `bili_cookies.txt` 复用。
4. **ffmpeg** 用 BtbN 的 GitHub release（2MB/s）；`gyan.dev` 只有 0.15MB/s，慢 13 倍。
5. **faster-whisper 模型**：`turbo` 别名指向 `mobiuslabsgmbh/faster-whisper-large-v3-turbo`；
   直连 HF 401、`HF_ENDPOINT` 不稳定 → 用 `hf-mirror.com` 逐个文件下到本地目录再当路径传。
6. **HTML 闯出标签**：`<svg>` 内写 `<code>` 会让解析器弹出 SVG 命名空间，
   该标签之后的整个 SVG 被丢弃、文字泄漏到图外。**必须用 `<tspan>`**。
7. **超长页 `full_page=True` 一次性截图会错位**：24254px 高的页面实测第 3 章章节头
   下移 983px 且章节强调色丢失 → PNG 与 DOM 坐标不再对应，按绝对 y 切片会切错，
   且缩略图看不出来。改为**按页面坐标分段 `clip` 截取再纵向拼接**（`work/shot_full.py`），
   并用「章节头强调色全宽横线」的 y 坐标做对齐自检。
